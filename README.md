# Lab Activity 7 – Data Mining and Visualization

# Project Overview
This project explores the **WW2 U-Boats dataset** from Kaggle.  
The dataset contains detailed records of German U-Boat operations during World War II, including patrols, ships sunk, tonnage, commanders, and fate events.  

The goal of this lab is to:
- Load and process the dataset using Python (pandas).
- Perform exploratory data mining.
- Generate interactive visualizations with Plotly.
- Run at least three test cases and save outputs as evidence.

## 📥 Dataset
- **Source:** [WW2 U-Boats – Kaggle](https://www.kaggle.com/datasets/cormac42/ww2-u-boats)  
- **File used:** `ww2_uboats.csv`  
- **Columns include:** Year, Merchant_Ships_sunk_No, Warships_sunk_n_total_loss_No, Patrols_Count, Wolfpacks_Count, Fate_Event, etc.
